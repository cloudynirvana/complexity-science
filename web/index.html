Complexity Science

An NSTG-guided computational study of pathology dynamics, built to explore in-silico pathway hypotheses under toxicity and comorbidity constraints. It is not clinical decision support and it has not been externally validated.

Problem

Host–burden dynamics in an oncology-relevant setting are not isolated from Nigerian comorbidity context: malaria, HIV, sickle cell disease, anaemia. The question this tool can pose is computational: which class-level biologic caricatures move a documented attractor under tighter host-stress caps? It cannot say which path is faster for a person.

Method

  1. NSTG research index. Placeholder summaries map a condition to themes, cautions, and comorbidities. Cite Federal Ministry of Health, Nigeria, Nigeria Standard Treatment Guidelines, 3rd edition, 2022. Official text is not on this page.
  2. MHBD-4. Four states — burden B, immune competence I, toxicity X, exposure E — with logistic growth, immune and stress modulation, and linear PK. Three archetypes are basins, not diagnoses.
  3. Constrained search. Checkpoint-like, TGF-β trap–like, cytokine-like, and fusion-mAb–like effectors are scored on burden, immune deficit, and toxicity, then filtered by caps the index tightened.

Outputs

A JSON/Markdown report: ranked in-silico hypotheses, the constraint rationale, downsampled trajectories, and a falsification checklist. Run locally: 

python -m complexity_science run \
  --archetype comorbidity_constrained \
  --conditions "malaria,hiv,sickle_cell,anaemia"

Non-claims

  • No cure language. No Phase II or FDA-ready phrasing.
  • Not clinically validated. Not a digital twin of a patient.
  • Not an executable NSTG protocol and not a Confluence clone.
